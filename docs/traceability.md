## What is not met, in one place

Three requirements are not fully met, and none of them is a surprise:

1. **R11 — Agent Teams.** The spec's picture is not what the tool does. A team was created with only
   the lead as a member; the named agents ran as background subagents; the three team hooks never
   fired; the task tools did not exist. Building on that picture would have shipped a feature that
   silently does nothing, so delphi uses `SubagentStop` — the event that actually arrives — and keeps
   `board.yaml` as the shared list it always was. See C-015 and C-016.
2. **R04 and R05 — published packages.** Everything is built and installs from source; publishing is
   Phase 7 and a mandatory stop point.
3. **R03 and R16 — two pieces of writing and one spike.** The comparison table, and whether a VS Code
   session joins the cross-session world. Neither blocks anything; the spike needs a person because it
   needs a session started inside VS Code.
